План: `docs/superpowers/plans/2026-10-21-preflop-trainer.md`. Спеки:
`docs/superpowers/specs/2026-10-21-preflop-call-model-design.md` (модель колла, Задачи 1–5) и
`docs/superpowers/specs/2026-10-21-preflop-trainer-design.md` (тренер, Задачи 6–10). Правила — те
же, что у плана 5, `docs/superpowers/state/2026-10-18-plan5-phases.md`, они отсылают к планам 4 и 3.

Фазы идут **строго по порядку**. Каждая сессия заканчивается отчётом и промптом следующей фазы.

## 1. Правила каждой фазы

Действуют §1.1–§1.7 документа фаз плана 3 (`2026-09-24-plan3-phases.md`) **дословно**, с заменами
плана 5 и этими:

| Там | Здесь |
|---|---|
| журнал плана 5 | `docs/superpowers/state/2026-10-21-plan6-execution-notes.md` (создаёт Фаза 1) |
| промпт `plan5-next-prompt.md` | `docs/superpowers/state/plan6-next-prompt.md` |
| реестр долгов §5 плана 5 | реестр §5 этого документа |
| сьют ~106–122 с | на входе 1100 passed, ~106–122 с в облаке (после Задачи 1 — ~177 с: равновесие сходится дольше, журнал «Фаза 1»; после Задачи 2 — 1167 passed, ~187 с; после Фазы 3b — 1215 passed, ~190 с); `addopts` уже `-q`; при отладке — только свой файл; тест T2 (Задача 3) добавит ~10–20 с |
| большие файлы, которые не читать целиком | `allin_matrix.json` (не читать вообще); план 6 целиком — читать «Решения по открытым вопросам», Global Constraints, Review Focus, Задачу своей фазы и Задачу, которую ревьюишь; спеки — разделы, названные в задаче |

Остальное без изменений: ревью делает следующая фаза — сначала соответствие спеке, потом качество
кода; чекпоинт между ревью и реализацией (больше пяти находок или больше одного коммита починки —
реализацию не начинать, задача уходит в фазу `kb`); мутанты руками по одному, откат
`git checkout -- <файл>`, с `PYTHONDONTWRITEBYTECODE=1` и чисткой `__pycache__`; мутанты — только
на закоммиченном коде; итог ревью — список находок или ровно `НАХОДОК НЕТ`, в журнал **до**
починки; одна починка — один `fix(engine): …`; решения против плана — блоком «Решения по находкам
ревью (Фаза N, дата)» или «Решения по ходу (Фаза N, дата)» в тексте задачи.

Дополнительно для плана 6:

- **Сверка с прототипом** (Global Constraints плана): в фазах Задач 1–2 числа таблиц R1–R3 спеки
  модели колла повторяются в ±1 п.п.; ревьюер следующей фазы повторяет одну точку сам.
- **Долгие замеры** (подбор Задачи 3, порог Задачи 5) — в фоне; результат — таблицей в журнал.
- **Стоп-условие** — только одно: подбор Задачи 3 не проходит допуски T2 и запасную форму. Тогда
  отчёт с таблицей отклонений и вопрос пользователю первым пунктом промпта; Задачи 4+ не
  начинаются.
